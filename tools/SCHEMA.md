# Формат юнита (data/units/unit-NNN.json)

Один файл = один юнит. NNN — номер с ведущими нулями (`unit-005.json`). Кодировка UTF-8, валидный JSON.
Эталон — `data/units/unit-001.json`. Проверка — `python -I tools/validate.py`.

```json
{
  "id": 5,
  "title": "I do/work/like etc. (present simple)",
  "summary": "Одно предложение на русском: о чём тема и когда её используют.",
  "ru": "<объяснение на русском, мини-разметка>",
  "en": "<то же объяснение на английском, мини-разметка>",
  "structure": "<построение: таблицы-формулы + отрицание/вопрос/краткий ответ, мини-разметка>",
  "exercises": [ ... 6–8 упражнений ... ]
}
```

## Мини-разметка (поля ru / en / structure / тексты заданий)
- `## Подзаголовок`
- `- пункт списка`
- `> пример` — блок примера (несколько строк `> ` подряд = один блок)
- `| A | B |` — таблица (первая строка — шапка; строка `|---|---|` допускается)
- `**жирный**`, `*курсив*`, `` `код` ``, `~~неверный вариант~~` (зачёркнутый красный)
- Пустая строка разделяет абзацы. В JSON перевод строки — `\n`.
- HTML не использовать (экранируется).

## Упражнения
Общие поля: `type` (`gap` | `choice` | `write`), `title`, `instruction` (на русском), необязательно `example`,
`source`: `"book"` — упражнение по мотивам учебника (тот же тип задания, **свои** предложения), `"ai"` — дополнительное авторское.

### gap — вставить пропуски
```json
{"type":"gap","source":"book","title":"Present simple: -s или нет?","instruction":"Поставьте глагол в нужную форму.",
 "items":[{"text":"My sister {{works}} in a bank.","hint":"work"},
          {"text":"They {{don't live|do not live}} here.","hint":"not / live"}]}
```
- `{{ответ}}` — поле ввода. Варианты через `|` (первый — показывается как правильный). В одном `text` может быть несколько пропусков.
- Сравнение без учёта регистра, лишних пробелов и точки в конце; ’ = '. Краткую и полную форму давать вариантами: `isn't|is not`.

### choice — выбор варианта (тест)
```json
{"type":"choice","source":"ai","title":"Выберите правильный вариант","instruction":"...",
 "items":[{"q":"She ___ coffee every morning.","options":["drink","drinks","is drinking"],"answer":1,
           "why":"Привычка → present simple; she → +s."}]}
```
- `answer` — индекс правильного варианта с 0. 3–4 варианта. `why` — короткое пояснение на русском (обязательно).

### write — письменное
```json
{"type":"write","source":"book","title":"Составьте предложения","instruction":"...",
 "items":[{"prompt":"(always / early / Sue / arrive)","answers":["Sue always arrives early."]},
          {"prompt":"Напишите о себе: как часто вы пьёте кофе?","sample":"I usually drink coffee in the morning."}]}
```
- `answers` — если ответ однозначен (автопроверка; можно несколько вариантов).
- `sample` — если ответ свободный (показывается образец, проверка самостоятельная). Можно и `answers`, и `sample`.

## Требования к содержанию
- **Не копировать текст учебника** (авторское право; сайт публичный): объяснения и предложения — свои. Тема, порядок подтем и типы заданий — как в юните учебника.
- `ru`: подробное, понятное объяснение для начинающих (A1–B1): когда используем, как образуется, сравнение с русским, типичные ошибки (`~~неверно~~ → верно`), 3–6 подзаголовков, много примеров с переводом.
- `en`: то же на простом английском (не дословный перевод `ru`, но те же пункты).
- `structure`: таблицы «утверждение / отрицание / вопрос / краткие ответы», правила написания (spelling), если есть.
- Упражнений 6–8: минимум 2 `gap`, 2 `choice`, 2 `write`; в каждом 5–10 пунктов. Примерно половина `book`, половина `ai`.
- Сложность растёт от первого упражнения к последнему; последнее — свободное письмо о себе (`sample`).
- Используйте только грамматику текущего и предыдущих юнитов, простую лексику.
- Ответы должны быть однозначными; если допустимо несколько — перечислить все через `|`.
